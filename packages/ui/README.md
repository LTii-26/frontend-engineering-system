# @frontend-engineering-system/ui

Shared React UI components for frontend-engineering-system.

## Install

```bash
pnpm add @frontend-engineering-system/ui react react-dom
```

## Usage

```tsx
import { Button } from "@frontend-engineering-system/ui"
import "@frontend-engineering-system/ui/styles.css"

export function Example() {
  return <Button>Save</Button>
}
```
